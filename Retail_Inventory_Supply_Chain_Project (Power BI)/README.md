# 📊 Retail Inventory & Supply Chain Analytics Dashboard

An interactive 7-page Power BI dashboard developed to analyze retail inventory and supply-chain performance, identify key trends and operational issues, and generate actionable insights for data-driven decision-making.

---

## 📌 Project Overview

The **Retail Inventory & Supply Chain Analytics Dashboard** is a Power BI-based business intelligence project designed to transform cleaned inventory and supply-chain data into meaningful visual insights.

The dashboard provides an interactive view of:

- 📦 Inventory and stock levels
- 📈 Sales performance
- 🚚 Logistics and received units
- 🏭 Warehouse operations
- 👥 Supplier performance
- 📋 Product performance
- ⚠️ Stockouts and lost sales
- 🔄 Reorder-level monitoring

The project demonstrates the complete process of preparing data, transforming it, creating analytical measures, developing KPIs, designing interactive dashboards, and using visual analysis to support data-driven business decisions.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze inventory levels and stock movement.
- Monitor sales and received units over time.
- Identify products below their reorder levels.
- Analyze stockout patterns and lost sales.
- Evaluate supplier contribution and performance.
- Analyze warehouse stock movement and spoilage.
- Compare product sales and inventory levels.
- Identify trends and potential operational issues.
- Generate actionable insights for better inventory and supply-chain decisions.
